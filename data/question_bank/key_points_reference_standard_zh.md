# 逐题 key_points 参考标准模板 v0.1（20 题 × 5–8 条，生成前锁定）

> **用途**：v2.0 主要结局的审计工具。每题的 key points 由**执笔医生**从指南/高质量系统综述预提炼，在**任何生成开始前**锁定并存证（Git 提交时间戳或邮件存档）——方案 §八红线，防「事后参照模型输出定标准」。
> **数量**：每题 5–8 条，20 题合计约 100–160 条。
> **写法要求**：每条 key point 必须可判「覆盖/未覆盖」（是/否），避免「提到质量」这类无法判定的模糊表述；涉及数字的条目给出文献口径的数值或区间。

---

## 每题固定格式（复制 20 份）

```
## Q__｜____（题号+简称）
- 主题：____　亚专业：A/T/S
- 执笔：____　复核：____　锁定时间：____（Git commit ID / 邮件主题）
- 溯源（本题 key points 所依据的指南/综述，题名检索取号）：
  1. ____
  2. ____

### Key points（5–8 条）
| # | key point（可判定表述） | 依据来源 | 覆盖判定口径说明 |
|---|---|---|---|
| 1 | | | |
| 2 | | | |
| … | | | |

### 每份回答的审计记录（评者填写，逐份一行入 /ratings/）
- 覆盖：n/N，未覆盖条目号：____
- 错误陈述：条数＋逐条摘录（含定位句）
- 不安全建议：是/否＋定位（如禁忌证误述）
- 引文真实性：逐条标注 真实存在 / 题录张冠李戴 / 完全虚构
```

---

## 格式示例（仅示范粒度，**非最终内容**——以 Q11 为例的三条草样，执笔医生须推翻重写）

| # | key point（示例粒度） | 说明 |
|---|---|---|
| 1 | 引用置钉准确度的对照证据（机器人 vs 徒手透视的 RCT/荟萃层面结果） | 只要求「引用了对照证据」这一可判定事实，不要求复现具体数字 |
| 2 | 区分「总体穿破率」与「临床显著穿破（如 ≥2 mm）」两种口径 | 考察回答是否混用口径 |
| 3 | 明确畸形/翻修人群的证据量级与一般人群不同（或说明证据不足） | 考察分层意识 |

> 上述三条仅示意「可判定」的写法标准；最终 key points 数量、内容、数值口径全部由执笔医生定稿。

---

## 流程提醒

1. 评者校准会议（方案 §3.4）：正式评分前用 10 份非入组样本试评，对齐 key-point 判定口径
2. 分歧 >1 分（Likert）或 key point 判定不一致时，第三评者裁定，裁定记录入 /ratings/
3. 匿名化逐条评分表随稿入补充材料（回应 R3#5）
