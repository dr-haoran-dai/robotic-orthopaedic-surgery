## 三、多重性与措辞纪律（冻结）

1. 主要族 = A1 的 3 检验，Holm 校正；**其余全部标注探索性**，不写进结论句的主张；
2. **禁用等价措辞**（"equivalent/on par"）；无显著差写 "no statistically significant difference detected in this question set"；
3. 天花板维度（一致性 Likert、不安全 0 事件）只报达标率/率+精确 CI；
4. 事后新增分析（冻结后）一律标 post hoc，进讨论不进摘要。
